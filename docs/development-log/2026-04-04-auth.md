# 인증 구현 기록

## 구현 내용

- Spring Security 폼 로그인을 설정했습니다.
- `/`, `/home`, `/register`, `/login` 경로를 공개 접근으로 허용했습니다.
- `PasswordEncoder`를 통해 BCrypt 비밀번호 해싱을 적용했습니다.
- 이메일 기준으로 회원을 로드하는 `CustomUserDetailsService`를 구현했습니다.
- 회원가입 및 로그인 컨트롤러를 추가했습니다.
- Spring Data JPA를 통해 회원 정보를 MySQL에 저장하도록 구현했습니다.

## 현재 모델

초기 구현에서는 `User`라는 이름을 사용했지만, 현재 도메인 모델은 `Member`를 사용하며 `members` 테이블에 저장됩니다.

## 사용 기술

- Spring Boot 4.0.5
- Spring Security
- Spring Data JPA
- MySQL
- Thymeleaf
